box-backup

box-backup is a personal backup tool used only by its owner, Harish Manoharan. It is not offered to anyone else.

Privacy policy

  • It uses Google Drive's drive.file permission, so it can only see and manage files that it created itself in the owner's Google Drive. It cannot read any other files.
  • It stores the owner's encrypted backups in that Drive folder. The data is encrypted on the owner's own computer before upload.
  • It collects no data from anyone else, uses no analytics, and shares nothing with third parties.
  • The owner can revoke its access at any time at myaccount.google.com/permissions.
