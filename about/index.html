I’m a software engineer at Purgo AI, working as an AI engineer on our data-engineering agent: a multi-agent LangGraph system that takes a data team’s ticket and writes the code for it in PySpark, SQL and dbt. I work across it, from retrieval and context engineering to prompts, orchestration and evals.

I designed the retrieval pipeline that finds the tables a ticket needs, chose its design by ablation on real tickets, and built several of the checks, and the recovery logic, in the loop that reviews the code it writes. I also built our two validation products end to end, which test AI models and Databricks platforms for life-sciences companies. I joined in June 2025 as an intern, on site that summer and then remote during my M.S. at UT Dallas, and have been full-time since June 2026.

On my own time I build products. ReadableSTEM (opens in a new tab) turns STEM course PDFs into accessible web pages, and I write down each test plan before running it, then publish every result, including the bars it didn’t reach. Margins (opens in a new tab) is a study app that makes students try before it helps, with the server, not the prompt, keeping the tutor from giving the answer away. Holdbrief (opens in a new tab) is an open-source daily brief on the stocks you follow, where code sets every number, a language model only writes the explanation, and a checker rejects any sentence the data doesn’t support.

Before Purgo I interned at Digitus in 2024, where I built a text-to-SQL agent and a RAG helpdesk assistant, and at PwC in 2023, on demand forecasting. From 2019 to 2024 I was at IIT Madras for a dual degree in biological sciences and data science, and wrote my master’s thesis with The Jackson Laboratory on finding behaviors in mouse videos without labels.
